# অধ্যায় ১৬
## Portfolio Management: ১০টি Domain থেকে ১০০টিতে যাওয়া

---

### 📦 একটা দোকানের মতো ভাবুন

একজন মুদি দোকানদার প্রতিদিন দেখেন — কোন জিনিস বিক্রি হচ্ছে, কোনটা shelf-এ পড়ে আছে, কোনটা expire হওয়ার আগেই বেচে দিতে হবে, কোনটায় stock বাড়ানো দরকার।

Domain portfolio manage করাটাও ঠিক এইরকম একটা দোকান চালানো।

শুধু domain কিনে রাখলেই হয় না — কোনটা রাখবেন, কোনটা ছাড়বেন, কোনটায় আরো invest করবেন — এই সিদ্ধান্তগুলোই আপনার portfolio-কে লাভজনক রাখে।

---

### 📊 Portfolio Track করার Spreadsheet

সব domain-এর তথ্য এক জায়গায় রাখুন। Google Sheets বা Excel-এ এই columns রাখুন:

| Column | কী লিখবেন |
|--------|-----------|
| Domain Name | পুরো domain (যেমন: SwiftPay.com) |
| Purchase Date | কবে কিনলেন |
| Purchase Price | কত USD দিয়ে কিনলেন |
| Registrar | Namecheap / GoDaddy / Dynadot |
| Expiry Date | কবে expire হবে |
| Asking Price | কত দামে list করেছেন |
| Listed On | Sedo / Dan.com / Afternic |
| Status | Active / Under Offer / Sold |
| Sale Price | কত দামে বিক্রি হলো |
| Net Profit | Sale Price − Purchase Price − Commission |
| Notes | বিশেষ কিছু (offer এসেছে কিনা ইত্যাদি) |

এই spreadsheet সপ্তাহে একবার update করুন।

---

### 🔍 কোন Domain রাখবেন, কোনটা ছাড়বেন?

প্রতি ৬ মাসে একবার portfolio review করুন।

**রাখার criteria:**
- ✅ Brandable এবং strong keyword আছে
- ✅ Comparable sales ভালো দেখাচ্ছে
- ✅ Offer এসেছে (মানে interest আছে)
- ✅ Renewal fee সাশ্রয়ী ($15 এর নিচে)

**ছেড়ে দেওয়ার criteria:**
- ❌ ১ বছরেরও বেশি সময় ধরে কোনো offer নেই
- ❌ Comparable sales data দুর্বল
- ❌ Renewal fee বেশি কিন্তু বিক্রির সম্ভাবনা কম
- ❌ Trend পরিবর্তন হয়েছে, domain আর relevant নয়

**ছেড়ে দেওয়ার মানে:** Simply renewal না দেওয়া — domain expire হয়ে যাবে। আর কোনো খরচ নেই।

> 💡 **মানসিকতা:** একটা domain ছেড়ে দেওয়া মানে হার না — এটা smart resource management। ঐ renewal fee দিয়ে একটা নতুন, better domain কিনুন।

---

### 🔁 Renewal Decision Framework

একটা domain renew করবেন কিনা সিদ্ধান্ত নিতে এই প্রশ্নগুলো করুন:

```
প্রশ্ন ১: গত ১২ মাসে কোনো offer বা inquiry এসেছে?
   হ্যাঁ → Renew করুন
   না ↓

প্রশ্ন ২: Comparable sales এখনো $200+ দেখাচ্ছে?
   হ্যাঁ → Renew করুন
   না ↓

প্রশ্ন ৩: Domain-এর niche এখনো growing?
   হ্যাঁ → Renew করুন
   না ↓

সিদ্ধান্ত: ছেড়ে দিন
```

---

### 💹 Revenue Reinvestment Strategy

প্রতিটা sale থেকে আয়ের কতটুকু reinvest করবেন?

**একটি sustainable model:**

```
প্রতিটা sale-এর পর:

৫০% → নতুন domain কেনায় reinvest
২০% → Renewal fee fund (আলাদা রাখুন)
২০% → নিজের জন্য (আয়)
১০% → Learning (tools, courses, resources)
```

শুরুতে হয়তো আয় কম — তাই সম্পূর্ণটাই reinvest করুন। যখন নিয়মিত বিক্রি হতে শুরু করবে, তখন এই ratio কাজে আসবে।

---

### 🏗️ Sub-Niche Portfolio Building

একটা smart strategy হলো নির্দিষ্ট niche-এ গভীরভাবে যাওয়া।

**কেন sub-niche portfolio কাজ করে:**

ধরুন আপনি fintech domain-এ specialize করলেন। এখন:
- আপনি জানেন কোন keyword valuable
- আপনি fintech buyer কোথায় খুঁজতে হয় জানেন
- একজন buyer কে ৫টি domain একসাথে বেচার সুযোগ আছে
- আপনার reputation ওই niche-এ তৈরি হয়

**Sub-niche portfolio উদাহরণ:**

**Fintech নিচ:**
- `QuickLend.com`
- `SwiftPay.com`
- `LoanBD.com`
- `PayTrack.com`
- `FinFlow.com`

এই ৫টা domain কোনো একটা fintech company-কে bundle-এ বেচলে $3,000–$8,000 পাওয়া সম্ভব।

---

### 🅿️ Domain Parking Income দিয়ে Renewal Fee Cover

Portfolio বড় হলে renewal fee একটা real cost হয়ে দাঁড়ায়।

Sedo Parking বা GoDaddy Parked Pages দিয়ে domain park করুন।

**বাস্তব expectation:**
- Type-in traffic আছে এমন domain: মাসে $5–$50
- নতুন domain, traffic নেই: মাসে $0–$2

এটা বড় আয় না — কিন্তু ২০–৩০টা domain park করলে বছরে কিছু renewal fee cover হয়।

**আরো ভালো বিকল্প:**
Domain park করার বদলে একটা simple "For Sale" landing page রাখুন — এতে organic buyer পাওয়ার সম্ভাবনা অনেক বেশি।

---

### 📈 Portfolio Growth Timeline

নতুন domainer হিসেবে realistic growth কেমন হতে পারে:

| সময়কাল | Portfolio | মাসিক আয় (আনুমানিক) |
|---------|-----------|---------------------|
| মাস ১–৩ | ৫–১০টি domain | $0–$50 (শেখার পর্যায়) |
| মাস ৪–৬ | ১০–২০টি domain | $50–$200 |
| মাস ৭–১২ | ২০–৪০টি domain | $200–$600 |
| বছর ২ | ৪০–৮০টি domain | $500–$1,500/মাস |
| বছর ৩+ | ৮০–১৫০টি domain | $1,500–$5,000+/মাস |

> ⚠️ **মনে রাখুন:** এগুলো average estimate। Domain flipping-এ income irregular — কোনো মাসে বড় sale হবে, কোনো মাসে কিছু না। Annual basis-এ হিসাব করা ভালো।

# অধ্যায় ১৭
## Domain Flipping থেকে Full Business: পরের ধাপ এবং ১২ মাসের Roadmap

---

### 🚀 Side Hustle থেকে Empire

২০১০ সালে Rick Schwartz — domain industry-তে "Domain King" নামে পরিচিত — একটা interview-এ বলেছিলেন:

> "আমি domain কিনেছিলাম কারণ আমি বিশ্বাস করতাম ইন্টারনেট একদিন সব কিছু পরিবর্তন করবে। আমি আগে থেকে position নিয়েছিলাম।"

তিনি ১৯৯৫ সালে adult content domain কিনেছিলেন পরে সেগুলো বেচে কোটি কোটি ডলার আয় করেছেন।

আপনাকে কোটিপতি হতে হবে না। কিন্তু "আগে থেকে position নেওয়া" — এই চিন্তাটা নিজের মধ্যে গেঁথে নিন।

Domain flipping শুধু একটা income source নয় — এটা ডিজিটাল দুনিয়া বোঝার একটা দরজা। এই দরজা দিয়ে আরো অনেক কিছুতে যাওয়া সম্ভব।

---

### পথ ১: Domain Flipping → Domain Brokerage

Domain broker মানে আপনি নিজে domain কিনবেন না — অন্যদের domain বিক্রি করিয়ে দেবেন commission-এর বিনিময়ে।

**কীভাবে কাজ করে:**
- একজন domain owner আপনাকে বলল তার `PrimeLand.com` বিক্রি করতে চায়
- আপনি তার হয়ে marketplace-এ list করলেন, buyer খুঁজলেন
- বিক্রি হলো $3,000-এ — আপনি ১৫–২০% commission পেলেন = $450–$600

**কেন এটা attractive:**
- নিজের capital লাগে না
- Risk নেই
- Network যত বড় হবে, income তত বাড়বে

**এখানে যেতে হলে:**
আগে নিজে ভালো flipper হন। তারপর reputation তৈরি হবে, তখন অন্যরা আপনাকে trust করবে।

---

### পথ ২: Domain Flipping → Hosting Reselling (Cross-Sell)

Domain buyer প্রায়ই hosting-ও খোঁজে। আপনি যদি domain বিক্রির পাশাপাশি hosting resell করেন:

- Domain: $50–$500 (একবার)
- Hosting: $200–$500/বছর (recurring)

Recurring income মানে প্রতি বছর টাকা আসছে — নতুন sale না হলেও।

এই বিষয়ে আপনার কাছে ইতিমধ্যে একটা reference আছে — যে ebook preview দেখেছিলেন সেখানে hosting reselling বিস্তারিত আলোচনা হয়েছে।

---

### পথ ৩: Domain Flipping → Website Flipping

এটা domain flipping-এর পরের level।

**পদ্ধতি:**
- একটা valuable domain কিনুন
- সেই domain-এ একটা simple website বানান (WordPress, ৫–১০টা article)
- কিছু organic traffic আসা শুরু করুন
- Flippa বা Empire Flippers-এ website সহ বেচুন

**কেন বেশি লাভ:**
- শুধু domain: $200–$2,000
- Domain + simple website + traffic: $2,000–$20,000+

Website flipping-এ technical knowledge একটু বেশি লাগে — কিন্তু return অনেক বেশি।

---

### পথ ৪: Personal Brand — "Domain Expert" হিসেবে পরিচিতি তৈরি

বাংলাদেশে domain flipping সম্পর্কে বাংলায় content তৈরি করা মানুষ এখনো খুব কম।

আপনি যদি:
- YouTube-এ Bangla domain flipping tutorial দেন
- Facebook-এ domain investing community চালান
- Blog লেখেন

— তাহলে আপনি শুধু domain থেকে নয়, content থেকেও আয় করতে পারবেন। এবং community-র মাধ্যমে buyer ও seller দুটোই পাবেন।

---

### 🌐 Community: কোথায় থাকবেন, কার সাথে মিশবেন

**আন্তর্জাতিক:**

- **DNForum.com** — আরেকটি established community
- **Twitter/X** — #domaining, #domains hashtag follow করুন

**বাংলাদেশ ও দক্ষিণ এশিয়া:**

- Freelancer community-তে domain flipping নিয়ে আলোচনা করুন
- না পেলে নিজেই একটা group তৈরি করুন — first mover advantage পাবেন

### 🗓️ ১২ মাসের Realistic Roadmap

এটাই এই বইয়ের সবচেয়ে practical অংশ।

---

#### 🟢 মাস ১–২: Foundation (ভিত্তি গড়ুন)

**লক্ষ্য:** শেখা এবং tools চেনা।

**করণীয়:**
- Namecheap, GoDaddy, Sedo, Dan.com, NamePros account খুলুন
- Payoneer account তৈরি করুন
- Google Sheets-এ portfolio tracker বানান
- NameBio-তে ১০০টা recent sale দেখুন — pattern বুঝুন
- ExpiredDomains.net explore করুন
- ChatGPT দিয়ে domain idea generate করার practice করুন

**কিনবেন না এখনো** — শুধু দেখুন এবং শিখুন।

---

#### 🟡 মাস ৩–৪: First Steps (প্রথম পদক্ষেপ)

**লক্ষ্য:** প্রথম domain কেনা এবং list করা।

**করণীয়:**
- বাজেট: $50–$100
- ৫টি carefully researched .com domain কিনুন
- প্রতিটার জন্য trademark check করুন
- Sedo + Dan.com + Afternic-এ list করুন
- প্রতিটার জন্য Dan.com-এ For Sale landing page বানান
- NamePros-এ account active করুন, community-তে অংশ নিন

**প্রত্যাশা:** হয়তো এখনো বিক্রি হবে না — এটা স্বাভাবিক।

---

#### 🟠 মাস ৫–৬: First Sale (প্রথম বিক্রি)

**লক্ষ্য:** প্রথম sale করা — যেকোনো দামে।

**করণীয়:**
- NamePros-এ domain list করুন (quick sale-এর জন্য)
- Outbound email শুরু করুন — ৫টি potential buyer-কে email করুন
- GoDaddy Auctions-এ expired domain monitor করুন
- Portfolio review করুন — কোনো domain ছেড়ে দেওয়া দরকার কিনা

**মানসিকতা:** প্রথম sale যদি মাত্র $50-এও হয় — celebrate করুন। System কাজ করছে, এটাই প্রমাণ।

---

#### 🔵 মাস ৭–৯: Momentum (গতি তৈরি)

**লক্ষ্য:** নিয়মিত sale, portfolio ২০–৩০-এ নিয়ে যাওয়া।

**করণীয়:**
- GoDaddy Auction-এ expired domain bid করা শুরু করুন
- Sub-niche বেছে নিন (fintech / healthtech / local BD)
- AI tools ব্যমহার বাড়ান — weekly AI workflow follow করুন
- প্রতিটা sale থেকে ৫০% reinvest করুন
- First sale-এর পর আত্মবিশ্বাস বাড়বে — সেটাকে কাজে লাগান

---

#### 🔴 মাস ১০–১২: Scale (বড় হওয়া শুরু)

**লক্ষ্য:** মাসিক $200–$500 আয়, ৩০–৫০টি domain portfolio।

**করণীয়:**
- Buy-and-Hold portfolio তৈরি শুরু করুন
- Premium expired domain (DA 30+) নিয়ে কাজ শুরু করুন
- Outbound marketing systematize করুন
- Personal brand তৈরির কথা ভাবুন (YouTube/Facebook)
- বার্ষিক income review করুন — tax planning করুন

---

#### ⭐ বছর ২ এবং তারপর

**লক্ষ্য:** Full-time income potential।

- ৫০–১০০+ domain portfolio
- মাসিক $500–$2,000+ আয়

### 💬 শেষ কথা: ধৈর্য, ধারাবাহিকতা, এবং data

Domain flipping-এ সফলতার তিনটি মূল উপাদান:

**১. ধৈর্য (Patience)**
বেশিরভাগ domain সাথে সাথে বিক্রি হয় না। সঠিক buyer সঠিক সময়ে আসে। তাড়াহুড়ো করে কম দামে বেচলে — সবচেয়ে বড় সুযোগ নষ্ট হয়।

**২. ধারাবাহিকতা (Consistency)**
সপ্তাহে ৫–১০ ঘণ্টা দিন। প্রতি সপ্তাহে নতুন domain research করুন। প্রতি মাসে portfolio review করুন। থেমে গেলে সব শেষ।

**৩. Data (তথ্য)**
মন দিয়ে domain কিনবেন না — data দিয়ে কিনবেন। NameBio, Google Trends, EstiBot — এই tools-ই আপনার সবচেয়ে বিশ্বস্ত advisor।

> এই তিনটি জিনিস থাকলে domain flipping-এ সাফল্য আসবেই।

════════════════════════════

□ Length 6–12 character?

□ No numbers?
□ Easy to pronounce?

□ EstiBot estimate দেখেছেন?

## Appendix D: Glossary — Technical Terms বাংলায়

| Term | বাংলা ব্যাখ্যা |
|------|---------------|
| Domain | ওয়েবসাইটের ইন্টারনেট ঠিকানা (যেমন: google.com) |
| TLD | Domain-এর শেষাংশ (.com, .net, .io) |
| Registrar | Domain বিক্রির আধিকারিক কোম্পানি (GoDaddy, Namecheap) |
| DNS | Domain Name System — ইন্টারনেটের phone book |
| WHOIS | Domain মালিকের তথ্য দেখার public database |
| DA (Domain Authority) | Moz-এর দেওয়া domain-এর strength score (0–100) |
| Backlink | অন্য website থেকে আসা link |
| Expired Domain | Renewal না দেওয়ায় মেয়াদ শেষ হওয়া domain |
| Aged Domain | পুরনো (৫+ বছর) domain |
| Auction | নিলাম — সর্বোচ্চ দামে বিক্রি |
| BIN (Buy It Now) | নির্দিষ্ট দামে সরাসরি কেনার option |
| Escrow | নিরাপদ তৃতীয় পক্ষের payment service |
| UDRP | Domain dispute resolution process (ICANN) |
| Cybersquatting | অন্যের brand নাম দিয়ে domain কিনে মুনাফা করার চেষ্টা |
| Domain Parking | Domain-এ বিজ্ঞাপন দেখিয়ে আয় করা |
| CPC | Cost Per Click — বিজ্ঞাপনদাতার প্রতি click-এর খরচ |
| Comparable Sales (Comps) | একই ধরনের domain-এর পূর্ববর্তী বিক্রয় রেকর্ড |
| EPP/Auth Code | Domain transfer করার জন্য দরকারী password |
| Outbound Marketing | নিজে থেকে buyer খোঁজা এবং contact করা |
| Portfolio | আপনার সব domain-এর সমষ্টি |
| Flip | কম দামে কিনে বেশি দামে বেচা |
| Drop | Domain expire হয়ে public-এ available হওয়া |
| Sniping | Auction-এর শেষ মুহূর্তে bid দেওয়া |
| Anchor Pricing | উঁচু দামে শুরু করে negotiation চালানোর কৌশল |
