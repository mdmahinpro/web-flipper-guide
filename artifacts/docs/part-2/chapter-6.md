# অধ্যায় ৬
## Domain Valuation: একটা Domain আসলে কত টাকার?

---

### 🤔 ১০ ডলারের domain কি $১০,০০০-এ বিক্রি হতে পারে?

**হ্যাঁ।** এবং এটা হয়েছেও।

কিন্তু কোন domain কত দামে বিক্রি হবে — এটা বোঝা domain flipping-এর সবচেয়ে গুরুত্বপূর্ণ দক্ষতা।

এই অধ্যায়ে আমরা শিখব:
১. Automated valuation tools কীভাবে ব্যবহার করবেন
২. Historical sales data দিয়ে "comparable" দেখা
৩. ৫টি factor যা domain-এর দাম নির্ধারণ করে
৪. নিজে manually valuation করার framework

---

### 🤖 Automated Valuation Tools — দ্রুত estimate পেতে

**Tool 1: EstiBot (estimbot.com)**

Domain flipping-এর দুনিয়ায় সবচেয়ে পরিচিত free tool।

কীভাবে কাজ করে:
- Domain name দিন
- AI analyze করে: keyword, length, extension, search volume, comparable sales
- একটা estimated value দেয়

সীমাবদ্ধতা:
- Brandable domain-এর "feel" বুঝতে পারে না
- Overestimate বা underestimate করতে পারে

**Tool 2: GoDaddy Free Appraisal**

GoDaddy-তে যেকোনো domain সার্চ করলে automatically একটা estimated value দেখায়। এটা machine learning ব্যবহার করে লক্ষ লক্ষ past sales analyze করে।

**Tool 3: Atom.com AI Appraisal**

Brandable domain-এর valuation-এ বেশি accurate। Startup culture বোঝে।

### 📊 NameBio — সবচেয়ে গুরুত্বপূর্ণ tool: Historical Sales Data

এটাই domain flipper-এর আসল "bible।"

**NameBio.com কী?**

NameBio হলো একটা database যেখানে ২০+ বছরের domain sale-এর record আছে — লক্ষাধিক domain কত দামে বিক্রি হয়েছে তার history।

**এটা কেন এত গুরুত্বপূর্ণ?**

ধরুন আপনি `SwiftPay.com` কিনতে চাইছেন $50-তে। কিন্তু এটা আসলে কত দামে বিক্রি হবে জানতে হলে দেখতে হবে — similar domain গুলো আগে কত দামে বিক্রি হয়েছে।

NameBio-তে search করুন "swift" বা "pay" — দেখুন similar domain-গুলো কত দামে বিক্রি হয়েছে।

**Comparable (Comps) analysis:**

| Similar Domain | বিক্রয় মূল্য | বছর |
|--------------|-------------|-----|
| PayTrack.com | $1,200 | 2023 |
| SwiftSend.com | $800 | 2024 |
| PayFlow.com | $2,500 | 2023 |
| SwiftPay.net | $450 | 2024 |

এই data দেখে আপনি বুঝতে পারবেন `SwiftPay.com` আনুমানিক $800–$2,000-এ বিক্রি হতে পারে।

**NameBio কীভাবে ব্যবহার করবেন:**

১. namebio.com-এ যান (account লাগে না basic search-এ)
২. Search bar-এ আপনার domain-এর keyword লিখুন (যেমন "swift" বা "pay")
৩. Results দেখুন — date, sale price, platform সব আছে
৪. Similar domain-গুলোর median price হলো আপনার "baseline"

### 💹 ৫টি Factor যা Domain-এর দাম নির্ধারণ করে

**Factor 1: Keyword Search Volume (সর্বোচ্চ গুরুত্ব)**

Google Keyword Planner-এ keyword-এর monthly search volume যত বেশি, domain তত valuable।

- ১০,০০০+ monthly searches = high value potential
- ১,০০০–১০,০০০ = medium value
- ১,০০০-এর নিচে = কম value

**Factor 2: CPC (Cost Per Click)**

Google-এ ঐ keyword-এর বিজ্ঞাপনের প্রতি click-এ advertiser কত দেয়।

- $5+ CPC = commercial value অনেক বেশি = domain বেশি valuable
- $0.5 নিচে = low commercial value

**Factor 3: Length এবং Pronunciation**

৪–৮ অক্ষরের domain > ১২ অক্ষরের domain (সবকিছু সমান থাকলে)

**Factor 4: Extension**

.com > .io > .net > .co > অন্যান্য

.ai ২০২৬-এ বিশেষভাবে valuable।

**Factor 5: Current Market Trends**

একটা "hot" niche-এর domain এই মুহূর্তে অনেক বেশি দামে বিক্রি হবে।

উদাহরণ: ২০২৩ সালে AI-related domain-এর দাম ৫–১০ গুণ বেড়েছে।

### 🏷️ Pricing Strategy: আপনার domain কত দামে list করবেন?

এটাই সবচেয়ে কঠিন সিদ্ধান্ত।

**একটি সহজ framework:**

```
আপনার কেনার দাম × ১০ = Starting price

তারপর comparable sales দেখে adjust করুন।
```

উদাহরণ:
- কিনলেন $15-তে
- Starting asking price: $150
- NameBio-তে similar domain দেখে মনে হচ্ছে $300–$600 realistic
- তাহলে list করুন $499-এ — negotiate করে $250–$300-এও দিতে পারেন

**BIN (Buy It Now) vs. "Make Offer":**

| মডেল | সুবিধা | অসুবিধা |
|------|-------|---------|
| BIN (fixed price) | দ্রুত বিক্রি হওয়ার সুযোগ | কম দামে আটকে যেতে পারেন |
| Make Offer | বেশি দাম পাওয়ার সুযোগ | বিক্রিতে বেশি সময় লাগে |

**সুপারিশ:** দুটোই রাখুন। BIN $1,000 রাখুন, Make Offer চালু রাখুন।

### 📈 Realistic Return Expectations

নতুনদের অনেক সময় অবাস্তব expectation থাকে। চলুন বাস্তবটা দেখি:

**Typical flip scenarios:**

| কেনার দাম | সম্ভাব্য বিক্রয় | সম্ভাব্য ROI |
|----------|----------------|------------|
| $10 | $50–$200 | 5x–20x |
| $10 | $500–$2,000 | 50x–200x (rare কিন্তু হয়) |
| $50 | $200–$500 | 4x–10x |
| $100 (expired) | $500–$2,000 | 5x–20x |
| $500 (premium expired) | $2,000–$10,000+ | 4x–20x+ |

**গুরুত্বপূর্ণ:** সব domain বিক্রি হয় না। একটা portfolio-তে হয়তো ১০টার মধ্যে ৩–৪টা বিক্রি হবে — কিন্তু সেই ৩–৪টার profit বাকি সবের renewal fee cover করে আরো বেশি দেবে।

### 🧮 Valuation Quick Checklist

কোনো domain কেনার আগে এই প্রশ্নগুলো করুন:

```
✅ Domain length ১২ অক্ষরের মধ্যে?
✅ Extension .com বা .io/.ai?
✅ Hyphens বা numbers নেই?
✅ Google Keyword Planner-এ search volume আছে?
✅ NameBio-তে comparable sales $200+ দেখাচ্ছে?
✅ EstiBot estimate $100+ দিচ্ছে?
✅ Trademark check পাস করেছে?
✅ কেনার দাম বিক্রয় দামের ২০%-এর নিচে?
```

এই ৮টি check পাস করলে domain কেনার কথা ভাবুন।
