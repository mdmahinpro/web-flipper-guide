# অধ্যায় ১১
## For Sale Landing Page: Buyer নিজে আসবে আপনার কাছে

---

### 🪟 আপনার domain-এ একটা "বিক্রয়ের সাইনবোর্ড"

ধরুন আপনি রাস্তায় হাঁটছেন। একটা বাড়িতে সুন্দর করে লেখা "For Sale" বোর্ড লাগানো — কোন এজেন্টের নম্বর আছে, বাড়ির brief description আছে।

আপনি interested হলে সহজেই যোগাযোগ করতে পারছেন।

এটাই হলো domain-এর **"For Sale Landing Page"** — আপনার domain-এ কেউ type করলে একটা professional page দেখতে পাবে যেখানে লেখা "এই domain বিক্রয়ের জন্য।"

---

### কেন Landing Page গুরুত্বপূর্ণ?

অনেক potential buyer সরাসরি browser-এ domain type করে দেখে সেটা কেউ ব্যবহার করছে কিনা।

যদি তারা blank page বা parked page দেখে — তারা হয়তো ভাববে domain available না, বা owner contact করতে চাইবে না।

কিন্তু যদি একটা professional "For Sale" page দেখে — তারা সহজেই offer করতে পারবে।

**গবেষণা বলছে:** Landing page থাকলে inbound inquiry ৩–৫ গুণ বেড়ে যায়।

---

### 🏗️ কীভাবে বানাবেন: দুটো সহজ পদ্ধতি

**পদ্ধতি ১: Dan.com-এর Free Landing Page**

Dan.com-এ domain list করলে automatically একটি professional landing page তৈরি হয়।

এই page-এ থাকে:
- "This domain is for sale" বার্তা
- Buy It Now price (আপনার দেওয়া)
- "Make Offer" বাটন
- Secure checkout

**কীভাবে করবেন:**
১. dan.com-এ account খুলুন
২. Domain add করুন
৩. Price বা "Make Offer" option set করুন
৪. Dan.com আপনাকে একটি nameserver দেবে — সেটা আপনার domain-এ point করুন

এরপর কেউ আপনার domain type করলে Dan.com-এর landing page দেখাবে।

---

**পদ্ধতি ২: Sedo Parking**

Sedo-তেও একটি "for sale" parking page পাওয়া যায়।

Sedo-র nameserver point করলে তারা আপনার domain-এ একটা branded "for sale" page দেখাবে।

---

### 📋 আদর্শ Landing Page-এ কী থাকবে?

**১. Clear "For Sale" Header**
সবার আগে visitor বুঝতে পারবে এটা বিক্রয়ের জন্য।

**২. Domain-এর Value Proposition**
সংক্ষেপে কেন এই domain valuable — ২–৩টা bullet point।

উদাহরণ:
```
✅ Short, memorable .com domain
✅ High search volume keyword
✅ Perfect for fintech or payment brands
```

**৩. Price বা "Make Offer" Option**
BIN price দিতে চাইলে দিন। না দিলে "Make Offer" রাখুন।

**৪. Contact Information বা Form**
Email বা contact form — সহজে contact করার ব্যবস্থা।

**৫. Trust Signals**
Escrow.com-এ secure payment-এর উল্লেখ।

### 📱 Nameserver পরিবর্তন: ধাপে ধাপে

Domain landing page কাজ করাতে আপনাকে domain-এর nameserver পরিবর্তন করতে হবে।

**GoDaddy domain-এর জন্য:**
১. GoDaddy-তে login করুন
২. "My Products" → domain-এ ক্লিক করুন
৩. "DNS" বা "Manage DNS" এ যান
৪. Nameserver পরিবর্তন করে Dan.com বা Sedo-এর nameserver দিন

**Namecheap domain-এর জন্য:**
১. Namecheap-এ login করুন
২. Domain list থেকে "Manage" click করুন
৩. "Nameservers" section-এ Dan.com/Sedo-এর nameserver দিন

::: info Nameserver পরিবর্তন কতক্ষণ লাগে?
সাধারণত ২৪–৪৮ ঘণ্টা পর থেকে কার্যকর হয়। এই সময়টাকে "DNS Propagation" বলে।
:::

---

### 🤔 Domain Parking vs. For Sale Landing Page

অনেকে "domain parking" শুনেছেন — এটা For Sale page-এর থেকে আলাদা।

**Domain Parking:** Domain-এ বিজ্ঞাপন দেখিয়ে ছোট আয় করা। Type-in traffic থেকে কিছু revenue।

**For Sale Landing Page:** Domain বিক্রির জন্য professional page।

**কোনটা ভালো?**

> For Sale landing page অনেক বেশি কার্যকর। Parking revenue খুব কম ($0–$5/মাস সাধারণ domain-এ), কিন্তু landing page একটা $500 sale এনে দিতে পারে।
