# Appendix D — Glossary: Technical Terms বাংলায়

Domain flipping-এ ব্যবহৃত সব important term-এর বাংলা ব্যাখ্যা।

---

## A–D

| Term | বাংলা ব্যাখ্যা |
|------|---------------|
| **Aged Domain** | পুরনো (৫+ বছর) domain — বেশি valuable কারণ পুরনো |
| **Anchor Pricing** | উঁচু দামে শুরু করে negotiation চালানোর কৌশল |
| **Auction** | নিলাম — সর্বোচ্চ bid-দাতার কাছে বিক্রি |
| **Auth Code / EPP Code** | Domain transfer করার জন্য দরকারী password |
| **Backlink** | অন্য website থেকে আসা link |
| **BIN (Buy It Now)** | নির্দিষ্ট দামে সরাসরি কেনার option (দরদাম নেই) |
| **Brandable Domain** | একটা কোম্পানি বা product-এর নাম হতে পারে এমন domain |
| **CPC (Cost Per Click)** | বিজ্ঞাপনদাতার প্রতি click-এর খরচ |
| **Comparable Sales (Comps)** | একই ধরনের domain-এর পূর্ববর্তী বিক্রয় রেকর্ড |
| **Cybersquatting** | অন্যের brand নাম দিয়ে domain কিনে মুনাফা করার চেষ্টা (illegal) |
| **DA (Domain Authority)** | Moz-এর domain-এর strength score (0–100) |
| **DNS** | Domain Name System — ইন্টারনেটের phone book |
| **Domain** | ওয়েবসাইটের ইন্টারনেট ঠিকানা (যেমন: google.com) |
| **Domain Parking** | Domain-এ বিজ্ঞাপন দেখিয়ে ছোট আয় করা |
| **Drop** | Domain expire হয়ে public-এ available হওয়া |

---

## E–N

| Term | বাংলা ব্যাখ্যা |
|------|---------------|
| **Escrow** | নিরাপদ তৃতীয় পক্ষের payment service — উভয় পক্ষকে protect করে |
| **Expired Domain** | Renewal না দেওয়ায় মেয়াদ শেষ হওয়া domain |
| **Flip** | কম দামে কিনে বেশি দামে বেচা |
| **Generic Domain** | কোনো specific brand নয়, সাধারণ keyword-based domain |
| **Make Offer** | Buyer তাদের ইচ্ছামতো দাম offer দিতে পারে |
| **Nameserver** | Domain-কে website-এর সাথে connect করে |

---

## O–Z

| Term | বাংলা ব্যাখ্যা |
|------|---------------|
| **Outbound Marketing** | নিজে থেকে buyer খোঁজা এবং contact করা |
| **Portfolio** | আপনার সব domain-এর সমষ্টি |
| **Premium Domain** | উচ্চ মূল্যের, highly brandable domain |
| **Registrar** | Domain বিক্রির আধিকারিক কোম্পানি (GoDaddy, Namecheap) |
| **Renewal** | Domain-এর মেয়াদ প্রতি বছর extend করা |
| **Sniping** | Auction-এর শেষ মুহূর্তে bid দেওয়া |
| **TF (Trust Flow)** | Majestic-এর domain trust score |
| **TLD** | Domain-এর শেষাংশ (.com, .net, .io, .ai) |
| **UDRP** | Domain dispute resolution process (ICANN) — trademark holder dispute করতে পারে |
| **WHOIS** | Domain মালিকের তথ্য দেখার public database |
| **WHOIS Privacy** | আপনার personal তথ্য WHOIS-এ লুকানোর service |
