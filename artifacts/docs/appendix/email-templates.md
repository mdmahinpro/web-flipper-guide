# Appendix C — Cold Email Template Collection

Proven email template যা buyer attract করে। নিজের style-এ customize করুন।

---

## Template 1: Business Owner-কে (General)

```
Subject: [Domain.com] — আপনার brand-এর জন্য

নমস্কার [Name],

[Company/Brand] সম্পর্কে জেনে ভালো লাগলো।

[Domain.com] domain-টি আমার কাছে আছে এবং 
আপনাদের brand identity-র সাথে এটা সুন্দরভাবে 
মিলে যায়।

আগ্রহী হলে কথা বলতে পারি।

ধন্যবাদ,
[আপনার নাম]
[যোগাযোগ]
```

## Template 2: Startup Founder-কে (English)

```
Subject: Quick question about [Domain.com]

Hi [Name],

Saw what you're building at [Startup Name] — 
great work.

I own [Domain.com] which matches your brand 
direction well. Open to a quick conversation 
if interested.

Best,
[Your Name]
```

## Template 3: Follow-up (৭ দিন পর)

```
Subject: Re: [Domain.com]

Hi [Name],

Just following up on my previous note about 
[Domain.com].

If timing isn't right, no worries at all. 
The domain will remain listed publicly soon.

Best,
[Your Name]
```

## Template 4: Premium Domain (Value-focused)

```
Subject: [Domain.com] — Brandable domain for [industry]

Hi [Name],

I noticed your company is in the [industry] space.

[Domain.com] is a premium, brandable domain that:
- Is short and memorable
- Ranks for "[keyword]" searches
- Similar domains have sold for $[X]–$[Y]

Asking: $[Price] via Escrow.com

Interested?

[Your Name]
```

---

## Template 5: Negotiation Counter-offer

```
Subject: Re: [Domain.com] — Counter Offer

Hi [Name],

Thank you for your offer of $[their offer].

Given the domain's keyword strength and 
comparable sales data (similar domains have 
sold for $[X]–$[Y] on NameBio), I'd like 
to counter at $[your counter].

I'm happy to complete the transfer via 
Escrow.com for security on both sides.

Let me know if this works.

[Your Name]
```

## ✅ Email লেখার Golden Rules

::: tip করুন
- Short রাখুন (৫০–১০০ শব্দ)
- Buyer-এর benefit-এ focus করুন
- একটা specific domain-এর জন্য লিখুন
- Escrow mention করুন — trust বাড়ে
:::

::: danger করবেন না
- "আমার domain অনেক দামি" — এই ধরনের দাবি
- Mass email পাঠানো (একসাথে ৫০ জনকে)
- Too long email
- Aggressive language
:::
