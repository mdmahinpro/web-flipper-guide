# 💰 পার্ট ৩: কেনার কৌশল
## *The Buy — কখন, কোথায়, কত দামে কিনবেন*

ভালো domain চেনার পর এলো আসল চ্যালেঞ্জ — সেটা সঠিক দামে এবং সঠিক জায়গা থেকে কেনা।

Domain কেনার তিনটি পথ আছে: auction, expired marketplace, এবং নতুন registration। প্রতিটার আলাদা কৌশল আছে।
